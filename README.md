# 1C Import Accounting — дипломный проект

Автономная конфигурация 1С:Предприятие 8.3 для управленческого учёта импортных поставок
ООО «Стройлайн». Сквозная цепочка из 8 документов (контракт → заказ → инвойс →
упаковочный лист → ГТД → приходная накладная → реализация → переоценка валютных
остатков), расчёт таможенных платежей (пошлина/сбор/НДС) по кодам ТН ВЭД,
себестоимость с распределением доп. расходов, списание по ФИФО в разрезе партий ГТД,
переоценка валютных обязательств (ПБУ 3/2006), спецотчёты по рентабельности по ГТД,
ролевая модель (Менеджер ВЭД / Кладовщик / Бухгалтер / Руководитель).

## Содержимое

- `диплом.docx` — полный текст дипломной работы.

## Ожидаемый результат

Сокращение времени обработки одной импортной поставки с 45 до 10–12 минут и полная
партионная прослеживаемость по номерам ГТД.
